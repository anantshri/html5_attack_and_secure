HTML5 Ping Attribute

Click the link below. The browser will send a POST request to track.php (with Ping-From / Ping-To headers) in addition to navigating to the target URL. No JavaScript is involved.

Visit example.com (tracked)
Server log will show:
POST /track.php HTTP/1.1
Ping-From: http://localhost/.../ping.html
Ping-To: https://example.com
